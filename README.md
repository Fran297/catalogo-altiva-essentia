# Altiva Essentia — Catálogo Exclusivo de Fragancias

Catálogo digital interactivo de Altiva Essentia: alta perfumería árabe y europea, organizada por casa de perfumería.

🔗 **Ver catálogo:** `https://fran297.github.io/catalogo-altiva-essentia/`

## Qué tiene
- 147 fragancias organizadas por casa (Lattafa, Armaf, Afnan, Rasasi, Maison Alhambra, y más)
- Buscador y filtros combinables por casa, familia olfativa y género
- Ficha por producto con notas, año de lanzamiento y duración estimada
- Modo oscuro / claro
- Botón directo a WhatsApp en cada precio y en el nombre de cada perfume
- Código QR de contacto

## Cómo actualizar el catálogo
1. Reemplazar el archivo `index.html` de este repositorio por la versión nueva.
2. Subirlo con **Add file → Upload files** en GitHub, confirmando el reemplazo.
3. El link no cambia — se actualiza solo en 1-2 minutos.

## Stack
Un único archivo HTML autocontenido (CSS + JS + imágenes embebidas). No requiere build ni instalación — se abre directo en cualquier navegador.
